Panduan Pengguna

Apa alat ini?

Alat ini membuat aturan OpenType calt untuk memilih bentuk alternatif berdasarkan huruf di sekitarnya. Anda tetap perlu menggambar glyph alternatif di font.

Cara menggunakan:

  1. Isi nama glyph dasar dan jumlah alternatif yang akan dibuat untuk masing-masing glyph.
  2. Buka Daftar glyph dan buat semua glyph alternatif di font editor, misalnya a.alt1 dan a.alt2.
  3. Untuk Glyphs, buka Font Info → Features → calt, klik Salin untuk Glyphs di halaman ini, tempel kode, lalu Compile. Jika font sudah punya kode calt, periksa dan gabungkan dengan hati-hati.
  4. Untuk alur build berbasis file fitur, klik Unduh .fea. File ini memuat kelas, dua lookup, dan fitur calt.
  5. Aktifkan fitur calt saat menguji font hasil ekspor. Tab Simulasi hanya menunjukkan pilihan alternatif; bentuk glyph asli perlu diperiksa di font editor.

Tentang Indikator Tabrakan:

Indikator ini menghitung pilihan alternatif yang berulang pada glyph yang sama secara berurutan. Aturan pencegah pengulangan sudah disertakan dalam file fitur yang diunduh. Periksa hasil akhir pada font yang sudah dikompilasi.

Penjelasan Parameter:

  • Lookahead Depth (Kedalaman Konteks): Menentukan berapa karakter ke depan yang dianalisis untuk memilih alternate. Nilai lebih tinggi = pola lebih kompleks dan acak. Rekomendasi: 2-4.
  • Alternatif per glyph: Berapa banyak variasi yang Anda buat untuk setiap glyph dasar. Rentang: 1–20.
  • Bucket (Ember): Algoritma membagi semua karakter ke dalam kelompok-kelompok kecil. Setiap bucket mendapat nomor unik yang digunakan untuk menghitung alternate mana yang dipilih berdasarkan konteks.
